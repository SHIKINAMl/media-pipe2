# media-pipe2

MediaPipe を使ったモーションキャプチャゲーム

カメラの前に立つだけで遊べる 2 種類のゲーム（ポーズ ゲーム / リズム ゲーム）を収録している。
メニュー操作もゲームも、すべて体の動きで行う。

## 配布版で遊ぶ

[Releases](https://github.com/SHIKINAMl/media-pipe2/releases) から `media-pipe2-<バージョン>.zip` をダウンロードして展開する。ゲームに必要なコードとモデルが入っている。

1. Python をインストールしておく（`python` コマンドが使える状態にする）
2. `setup.bat` を実行する（初回のみ。`.venv` の作成と必要なパッケージのインストール）
3. `run.bat` を実行するとゲームが起動する

Web カメラが必要。

配布用の zip は次のコマンドで作成できる（`dist/` に出力される）:

```powershell
.\.venv\Scripts\python.exe package_release.py v0.1.0-beta
```

## セットアップ

このワークスペースでは `.venv` を使用

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install mediapipe opencv-python
```

インストール確認:

```powershell
.\.venv\Scripts\python.exe -m pip show mediapipe
.\.venv\Scripts\python.exe -m pip show opencv-python
```

## 起動

```powershell
.\.venv\Scripts\python.exe main.py
```

`models/hand/hand_landmarker.task` と `models/pose/pose_landmarker_*.task` が必要

## ゲームの開始方法

1. **タイトル画面**: カメラの前に立ち、体と手が映る状態を約 1 秒保つとゲーム選択へ進む（人型のガイドが出ている間は体が検出されていない）。
2. **ゲーム選択**: 左上のボタンがポーズ ゲーム、右上のボタンがリズム ゲーム。右横のトロフィーはランキング表示。
3. **難易度選択**: 星 1 つ（かんたん）/ 星 2 つ（ふつう）/ 星 3 つ（むずかしい）から選ぶ。左横のボタンで戻る。
4. **立ち位置確認**: 画面の枠内に必要な部位が映ると、上部の点が緑になる。すべて緑の状態を約 2 秒保つと自動で次へ進む。
   - ポーズ ゲーム: 肩と腰、両手（ふつう以上は両足も）
   - リズム ゲーム: 両肩と手（かんたんは片手でよい、ふつう以上は両手）
5. **カウントダウン**: 3・2・1 のあとゲーム開始。
6. **結果画面**: スコアと順位（5 位以内のとき）が表示される。左のボタンで同じ設定でもう一度、右のボタンでゲーム選択へ戻る。

操作がないまま 30 秒（結果画面は 20 秒）経つと、自動でタイトル画面へ戻る。

## 操作方法

### メニュー操作

- 画面にはプレイヤーの動きを鏡写しにしたアバターが表示され、**両手がそのままカーソル**になる。
- ボタンは肩のまわりの、腕を伸ばせば届く位置に配置される。
- **ボタンに手を 1 秒かざす**と決定（ボタンのまわりのリングが 1 周すると決定）。
- **ボタンの上で手を握る（グー）**と、待たずにすぐ決定できる。
- 右上隅の終了ボタンは運営用で、2 秒かざし続けると終了する（グーでの即決定は不可）。

### プレイ中

- プレイ中に体が映らなくなると一時停止する。10 秒以内に映り直せば 3 カウントのあと再開し、戻らなければタイトルへ戻る（ランキング登録なし）。
- 画面右下の点は検出状態を表す（緑 = 体を検出中）。

## ゲームルール

### ポーズ ゲーム（GAME_A）

画面に出る丸に、指定された手足を合わせてキープしていくゲーム。

- 点線の丸の中に指定の部位を入れ、**約 0.65 秒とどめると成功**。成功すると次の丸が出る。
- 成功した丸は実線になり、**その部位を丸に入れたままキープ**しながら次の丸をねらう。キープ数の上限を超えると、古い丸から順に解放される。
- 丸ごとに制限時間があり、画面上部に残り時間が表示される。
- 上体を大きく傾けている間（約 35 度以上）は成功にならない（アバターの胴体の色が変わる）。
- 成功を重ねるほど、制限時間は短く（下限 1.5 秒）、丸は小さくなっていく。

**ゲーム終了の条件**

- 制限時間内に丸へ合わせられなかった
- キープ中の部位が丸から外れた（約 0.4 秒の猶予あり。外れかけると丸が黄色くなる）

**スコア**: 1 回の成功につき `100 + 残り秒数 × 20 + キープ中の数 × 50` 点

**部位の色と記号**

| 部位 | 色 | 記号 |
| --- | --- | --- |
| 左手 | 水色 | 丸 |
| 右手 | ピンク | ひし形 |
| 左足 | 黄色 | 三角 |
| 右足 | 緑 | 四角 |

**難易度**

| 難易度 | 使う部位 | 左右の指定 | キープ上限 | 最初の制限時間 |
| --- | --- | --- | --- | --- |
| かんたん | 手だけ | どちらでもよい | 1 か所 | 6 秒 |
| ふつう | 手と足 | どちらでもよい | 2 か所 | 5 秒 |
| むずかしい | 手と足 | 左右も指定される | 3 か所 | 4 秒 |

### リズム ゲーム（GAME_B）

リズムに合わせて、グー・チョキ・パーで丸（ノーツ）をタッチするゲーム。

- 丸の中には手の形の記号が描かれている。**丸に手を重ね、同じ手の形で、タイミングよく**タッチする。
- 外側の輪が縮んで丸に重なった瞬間がタイミング。画面上部のレーンでも、次に来るノーツとタイミングを確認できる。
- 2 つの丸が点線でつながったノーツは、**両手で同時に**タッチする。
- 続けて成功するとコンボが増える。ミスするとコンボは 0 に戻る。
- ノーツが進むにつれて、テンポが少しずつ速くなる。
- 画面左下には、現在認識されている左右の手の形が表示される。

**ゲーム終了の条件**: ミスが 5 回になると終了（画面右上に ✕ で表示）

**判定とスコア**

| 判定 | 条件 | 点数 |
| --- | --- | --- |
| パーフェクト | ジャストのタイミング（判定幅の 40% 以内） | 300 |
| グッド | 判定幅の範囲内 | 100 |
| ミス | 判定幅を過ぎた、または場所・手の形・手の左右が違う | 0 |

- 両手ノーツは点数が 1.5 倍
- コンボ ボーナスとして `コンボ数 × 5` 点が加算される

**手の形の色**: グー = ピンク / パー = 黄色 / チョキ = 水色

**難易度**

| 難易度 | 手の形 | 両手ノーツ | 左右の指定 | 開始テンポ | 判定幅 |
| --- | --- | --- | --- | --- | --- |
| かんたん | グー・パー | なし | なし | 80 BPM | ±0.30 秒 |
| ふつう | グー・チョキ・パー | あり | なし | 100 BPM | ±0.23 秒 |
| むずかしい | グー・チョキ・パー | あり | あり（両手ノーツで左右が切り替わる） | 120 BPM | ±0.18 秒 |

### ランキング

- スコアはゲームと難易度ごとに記録され（上位 20 件まで保存）、ランキング画面には上位 5 件が表示される。
- ランキング画面では、左のボタンでゲーム、右のボタンで難易度を切り替える。
- 記録は `games/ranking.json` に保存される。

## 運営用キー操作

| キー | 動作 |
| --- | --- |
| `F11` / `Esc` | フルスクリーン切替 / 解除 |
| `F5` | タイトルへリセット（カメラ・モデルエラー時は再初期化） |
| `F1` | 診断表示（FPS、検出状態、Canvas 要素数） |
| `Enter` | 立ち位置確認をスキップしてカウントダウン開始 |
| `BackSpace` | プレイ中のゲームを中断してゲーム選択へ（ランキング登録なし） |
| `Ctrl+Shift+R` を 3 秒以内に 2 回 | ランキングリセット |

マウスクリックは常に代替入力として使える。操作ログは `logs/session.log` に出力される。
