# media-pipe2

MediaPipe を使ったモーションキャプチャゲーム

## セットアップ

このワークスペースでは `.venv` を使用

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install mediapipe opencv-python
```

インストール確認:

```powershell
.\.venv\Scripts\python.exe -m pip show mediapipe
.\.venv\Scripts\python.exe -m pip show opencv-python
```
